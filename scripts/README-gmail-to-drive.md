# صندوق الطلبات — Gmail إلى Drive

## التركيب (مرة واحدة، ٣ دقايق)

1. افتح [script.google.com](https://script.google.com) وانت داخل بـ`company@bluebug.io`
2. **New project**
3. امسح اللي في `Code.gs` والصق محتوى [`gmail-to-drive.gs`](gmail-to-drive.gs)
4. من القايمة فوق اختار الدالة **`setUp`** واضغط **Run**
5. هيطلبلك صلاحيات Gmail و Drive — وافق

خلاص. بيشتغل كل عشر دقايق لوحده.

> الشاشة هتقولك "Google hasn't verified this app" — ده طبيعي لأن
> السكريبت بتاعك انت. اضغط **Advanced** ← **Go to project (unsafe)**.
> الكلمة مخيفة بس هي بتتقال لأي سكريبت شخصي، والكود ده قدامك كله.

## بيعمل إيه

```
رسالة جديدة  →  لِيبل "Applications"
             →  تخرج من الإنبوكس
             →  المرفقات في Drive: Applications/<المرشّح>/
             →  صف في شيت "Applications Log"
```

المتراكم (الـ٢٠٠ طلب) بياخد دوره على مدار كام تشغيلة — ٤٠ محادثة
في المرة عشان ميوصلش لحد الـ٦ دقايق بتاع Apps Script.

## الشيت

| العمود | إيه |
|---|---|
| Date · Name · Email | من الرسالة |
| Subject · Message | العنوان وأول ٥٠٠ حرف |
| Files · File link | أسماء المرفقات ولينك أول ملف |
| Message ID | ده اللي بيمنع التكرار — متغيّرهوش |
| **Status** | فاضي، تملاه انت |

## إعدادات تقدر تغيّرها

في أول الملف:

| | |
|---|---|
| `ARCHIVE` | خليها `false` لو عايز الرسايل تفضل في الإنبوكس |
| `QUERY` | `newer_than:30d` — وسّعها لو عايز أقدم |
| `MAX_THREADS` | ٤٠ في التشغيلة |
| `ALLOWED` | امتدادات المرفقات المقبولة |

## الأمان

المرفقات جاية من ناس مش معروفين، فالسكريبت:

- بيشيل أي مسار من اسم الملف (`../../x.pdf` بيبقى ملف واحد جوّه المجلد)
- بيقبل امتدادات المستندات بس — `.exe` و`.zip` **مابيتكتبوش على Drive أصلاً**
- سقف ١٥ ميجا للمرفق
- بيخزّن وبس: مابيفتحش ولا بينفّذ ولا بيرد على حاجة

## تشوف اللي بيحصل

في محرر Apps Script: **Executions** على الشمال — كل تشغيلة وعدد اللي اتنقل.
